# OpenStreamBox (working name)

My open project about IRL streaming: streaming live from outside, on the move. I'm writing down how I see the IRL streaming ecosystem, what works today and who built it, what is still hard, and a roadmap of what I'm building.

**Site:** [openstreambox.org](https://openstreambox.org) · **Discord:** [discord.gg/3B9b9n9N6](https://discord.gg/3B9b9n9N6) (one quiet channel, DM me there)

## What's here

- **Open formats I'm working on:** [stream-status](https://github.com/openstreambox/stream-status), one shape for "what's wrong with the stream, where, and is it still live", and [stream-session](https://github.com/openstreambox/stream-session), so every device in one live show agrees on which show it is and who decides right now. Both are early drafts. Issues and ideas are welcome there.
- **Open data:** [irl-commons](https://github.com/irl-commons/irl-commons) lives in its own organisation, so any project can use it and help improve it.
- **Working forks.** Most repositories here are forks of the projects OpenStreamBox builds on: BELABOX, CeraLive, Moblin, Moblink, srtla, OBS and many more. I use them to test changes and prepare fixes before I send them upstream. **They are not the projects.** For issues, questions, discussions and pull requests, please go to the original repository. Each fork links to it at the top.
