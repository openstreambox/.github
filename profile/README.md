# OpenStreamBox

Reference build and working forks. Part of [IRL Commons](https://irlcommons.org).

OpenStreamBox is a reference backpack build for IRL streaming: the hardware and software I put together and document, so others can repeat it or build on it. It's not ready yet.

## What's here

- **Working forks.** Most repositories here are forks of the projects the reference build relies on: BELABOX, CeraLive, Moblin, Moblink, srtla, OBS and many more. I use them to test changes and prepare fixes before I send them upstream. **They are not the projects.** For issues, questions, discussions and pull requests, please go to the original repository. Each fork links to it at the top.
- **Open standards and open data** live in [IRL Commons](https://github.com/irl-commons): [stream-status](https://github.com/irl-commons/stream-status), [stream-session](https://github.com/irl-commons/stream-session) and [irl-commons](https://github.com/irl-commons/irl-commons).
- **For streamers:** plain guides, a glossary and a link list of apps and services are on [howtoirl.org](https://howtoirl.org).
